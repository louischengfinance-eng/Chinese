# 🔮 線上算命系統

一個基於傳統命理學的現代化網頁應用系統，整合了紫微斗數、八字命理、易經六爻三大命理系統。

## ✨ 功能特點

### 三大命理系統

1. **八字命理**
   - 自動計算年柱、月柱、日柱、時柱
   - 五行分析（木、火、土、金、水）
   - 日主分析與命格特點
   - 喜用神推算

2. **紫微斗數**
   - 十二宮位自動排盤
   - 十四主星定位
   - 命宮、身宮分析
   - 五行局計算
   - 整體格局解析

3. **易經六爻**
   - 基於生辰的卦象生成
   - 六十四卦解析
   - 卦辭詳解
   - 事業、財運、感情、健康全方位分析

## 🎯 使用方法

### 線上使用

1. 直接在瀏覽器中打開 `index.html` 文件
2. 填寫個人基本資料：
   - 姓名
   - 性別
   - 出生日期
   - 出生時辰
   - 占卜問題（選填）
3. 點擊「開始算命」按鈕
4. 查看詳細的命理分析結果

### 本地部署

```bash
# 克隆或下載項目
git clone <repository-url>

# 進入項目目錄
cd Chinese

# 使用任何HTTP服務器啟動（可選）
# 方式1: 使用Python
python -m http.server 8000

# 方式2: 使用Node.js
npx http-server

# 方式3: 直接雙擊 index.html 文件
```

訪問 `http://localhost:8000` 或直接打開 `index.html`

## 📊 算法說明

### 八字計算

- **年柱**：基於公曆年份，使用干支紀年法
- **月柱**：五虎遁月口訣計算
- **日柱**：基於日期序數計算
- **時柱**：五鼠遁日起時法計算
- **五行分析**：統計八字中五行分布
- **喜用神**：基於五行強弱分析

### 紫微斗數

- **命宮定位**：基於生月和生時計算
- **身宮定位**：順時針推算
- **五行局**：根據出生年份確定
- **主星排布**：紫微星系和天府星系自動排列
- **格局分析**：根據命宮主星判斷

### 易經六爻

- **卦象生成**：基於生辰信息生成六爻
- **卦象查詢**：對應六十四卦系統
- **卦辭解釋**：提供詳細的吉凶分析
- **多維度解析**：事業、財運、感情、健康
