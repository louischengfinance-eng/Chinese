# 🔮 線上算命系統

一個基於傳統命理學的現代化網頁應用系統，整合了**紫微斗數**、**八字命理**、**易經六爻**、**奇門遁甲**四大命理系統，採用精美的卡片式設計風格。

## ✨ 功能特點

### 🎴 四大命理系統

- ✅ 日主分析與命格特點解讀
- ✅ 喜用神、用神、忌神智能推算

- ✅ 五行局自動判定

## 🚀 使用方法

### 在線使用

1. **打開系統**
   - 直接在瀏覽器中打開 `index.html` 文件
   - 或部署到任何Web服務器

2. **填寫資料**
   - 姓名：輸入您的姓名
   - 性別：選擇性別（影響紫微斗數分析）
   - 出生日期：選擇公曆出生日期
   - 出生時辰：選擇對應的時辰（十二時辰）
   - 占卜問題（選填）：輸入您想問的問題（用於易經和奇門遁甲）

3. **開始算命**
   - 點擊「開始算命」按鈕
   - 欣賞燒符動畫特效 🔥
   - 等待系統計算（約3-4秒）
   - 查看詳細的四大命理分析結果

4. **查看結果**
   - 滾動瀏覽各個命理系統的分析
   - 每個卡片都可以單獨查看
   - 支持打印保存結果

5. **重新測算**
   - 點擊「重新算命」按鈕
   - 可以修改資料進行新的測算

### 本地部署

```bash
# 方式1: 直接打開
# 雙擊 index.html 文件即可在瀏覽器中打開

# 方式2: 使用 Python 簡單服務器
python -m http.server 8000
# 訪問 http://localhost:8000

# 方式3: 使用 Node.js http-server
npx http-server
# 訪問顯示的地址

# 方式4: 使用 VS Code Live Server
# 安裝 Live Server 擴展後，右鍵選擇 "Open with Live Server"
```

## 📊 算法說明

### 八字計算
- **年柱**: 基於公曆年份，使用干支紀年法
- **月柱**: 五虎遁月口訣計算
- **日柱**: 基於日期序數的干支演算
- **時柱**: 五鼠遁日起時法計算
- **五行分析**: 統計天干地支五行分布
- **喜用神**: 基於五行強弱平衡原理

### 紫微斗數
- **命宮定位**: 基於生月和生時的逆時針推算
- **身宮定位**: 基於生月和生時的順時針推算
- **五行局**: 根據出生年份確定納音五行局
- **主星排布**: 紫微星系和天府星系的自動排列演算法
- **格局分析**: 根據命宮主星組合判斷命格特點

### 易經六爻
- **卦象生成**: 基於生辰信息的確定性演算法（非隨機）
- **卦象查詢**: 匹配六十四卦數據庫
- **卦辭解釋**: 提供詳細的吉凶和建議
- **多維分析**: 事業、財運、感情、健康全方位解讀

### 奇門遁甲 ⭐
- **局數判定**: 根據月份和日期確定陰遁或陽遁局
- **值符值使**: 基於時辰計算
- **九宮排盤**: 自動排列八門、九星、八神
- **用神定位**: 根據問題類型智能選擇用神宮位
  - 財運問題 → 生門
  - 事業問題 → 開門
  - 感情問題 → 六合
  - 考試問題 → 景門
  - 健康問題 → 天心
- **吉凶判斷**: 綜合門、星、神進行評分
- **建議生成**: 根據吉凶等級提供行動建議
